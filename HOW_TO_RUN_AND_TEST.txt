================================================================================
                              1. PROJECT OVERVIEW
================================================================================

This project implements a comprehensive Zero Trust network architecture on AWS,
featuring:
- Micro-segmentation with VPC subnets
- Private connectivity using AWS PrivateLink
- Identity-based access control with Amazon Cognito
- Continuous monitoring with VPC Flow Logs and GuardDuty
- Node.js backend API with JWT authentication
- Docker containerization
- Infrastructure as Code with Terraform

                           2. PREREQUISITES INSTALLATION
================================================================================

2.1 INSTALL REQUIRED TOOLS
---------------------------

# Update system packages
sudo apt update && sudo apt upgrade -y

# Install Node.js (if not already installed)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Install Terraform
curl -LO https://releases.hashicorp.com/terraform/1.6.3/terraform_1.6.3_linux_amd64.zip
unzip terraform_1.6.3_linux_amd64.zip
sudo mv terraform /usr/local/bin/
rm terraform_1.6.3_linux_amd64.zip

# Install AWS CLI (if not already installed)
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
rm -rf aws awscliv2.zip

# Install Docker (if not already installed)
sudo apt-get install -y docker.io
sudo systemctl start docker
sudo systemctl enable docker
sudo usermod -aG docker $USER

# Install jq for JSON parsing (optional but helpful)
sudo apt-get install -y jq

2.2 VERIFY INSTALLATIONS
-------------------------
node --version          # Should show v20.x.x or higher
npm --version           # Should show 10.x.x or higher
terraform version       # Should show v1.6.3 or higher
aws --version          # Should show aws-cli/2.x.x
docker --version       # Should show Docker version 20.x.x

-------------------------

# Test 2: Protected endpoint with invalid token (should return 401)
curl -w "%{http_code}" -H "Authorization: Bearer invalid-token" \
     http://localhost:8080/api/protected/dashboard

# Test 3: Check response headers for security
curl -I http://localhost:8080/health

4.5 PERFORMANCE TESTING
------------------------
# Simple response time test
curl -w "Response time: %{time_total}s\n" -o /dev/null -s http://localhost:8080/health

# Load test (10 concurrent requests)
for i in {1..10}; do
    curl -s -w "%{time_total}\n" -o /dev/null http://localhost:8080/health &
done
wait

# Calculate average response time
for i in {1..10}; do 
    curl -s -w "%{time_total}\n" -o /dev/null http://localhost:8080/health; 
done | awk '{sum+=$1; count++} END {print "Average:", sum/count "s"}'

4.6 SECURITY HEADERS VERIFICATION
----------------------------------
# Check all security headers
curl -I http://localhost:8080/health | grep -E "(Security|Policy|Protection|Frame|Content)"

# Expected headers:
# Content-Security-Policy: (should be present)
# Strict-Transport-Security: (should be present)
# X-Content-Type-Options: nosniff
# X-Frame-Options: SAMEORIGIN
# X-XSS-Protection: 0

4.7 RATE LIMITING TEST
----------------------
# Test rate limiting (should start blocking after 100 requests)
for i in {1..105}; do
    echo "Request $i: $(curl -s -w "%{http_code}" -o /dev/null http://localhost:8080/health)"
done

                            9. TROUBLESHOOTING
================================================================================

9.1 COMMON ISSUES AND SOLUTIONS
--------------------------------

ISSUE: "npm install" fails
SOLUTION: 
- Check Node.js version: node --version (should be 18+)
- Clear npm cache: npm cache clean --force
- Delete node_modules and package-lock.json, then reinstall

ISSUE: Server won't start
SOLUTION:
- Check if port 8080 is already in use: lsof -i :8080
- Kill existing processes: pkill -f "node server.js"
- Check server.log for error messages

ISSUE: Terraform validation fails
SOLUTION:
- Run terraform init
- Check AWS credentials: aws sts get-caller-identity
- Verify terraform.tfvars configuration

ISSUE: Docker build fails
SOLUTION:
- Check Docker daemon: sudo systemctl status docker
- Check disk space: df -h
- Clean Docker cache: docker system prune

ISSUE: AWS deployment fails
SOLUTION:
- Verify AWS credentials and permissions
- Check AWS service limits
- Review CloudTrail logs for error details
