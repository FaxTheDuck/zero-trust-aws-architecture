🔒 SECURITY LAYERS:

Layer 1: Network ACLs (Subnet Level)
├─ Public: Allow HTTP/HTTPS in, App ports out
├─ App: Allow App ports in, DB ports out  
└─ DB: Allow DB ports in, Ephemeral out

Layer 2: Security Groups (Instance Level)
├─ ALB: Internet → ALB, ALB → App
├─ App: ALB → App, App → DB
├─ DB: App → DB only
└─ VPC Endpoints: Private subnets → AWS services

Layer 3: IAM (Identity Level)
├─ Cognito: User authentication & authorization
├─ Instance Roles: Service-specific permissions
├─ Conditional Policies: VPC/IP restrictions
└─ Resource-based Policies: Deny external access

## Network Flow Details

### Ingress Traffic Flow
1. **Internet** → **ALB** (Public Subnet)
   - Ports: 80, 443
   - Protection: WAF, Security Groups

2. **ALB** → **App Servers** (Private Subnet)
   - Port: 8080 (configurable)
   - Security: ALB → App security group reference

3. **App Servers** → **Database** (Private DB Subnet)
   - Port: 5432 (PostgreSQL)
   - Security: App → DB security group reference

### Egress Traffic Flow
1. **App Servers** → **AWS Services**
   - Via: VPC Endpoints (PrivateLink)
   - Services: S3, DynamoDB, CloudWatch, etc.

2. **App Servers** → **Internet** (if needed)
   - Via: NAT Gateway (limited use)
   - Ports: 80, 443 only

3. **Database** → **Nowhere**
   - Complete isolation from internet
   - Internal VPC communication only

### Administrative Access
1. **SSH Access** → **Bastion** → **App Servers**
   - Bastion in public subnet
   - Restricted source IPs
   - MFA recommended

## Zero Trust Validation Points

- ✅ **No Trust Zones**: Each layer explicitly verified
- ✅ **Least Privilege**: Minimum required access only
- ✅ **Micro-segmentation**: Network isolation between tiers  
- ✅ **Identity Verification**: Cognito + IAM integration
- ✅ **Continuous Monitoring**: Flow logs + GuardDuty
- ✅ **Encrypted Transit**: HTTPS/TLS everywhere
- ✅ **Private Connectivity**: PrivateLink for AWS services
